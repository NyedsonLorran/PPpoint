

# PPoint

<img align="right" width="300" src="https://github.com/user-attachments/assets/8ee82d45-b4ed-4f72-b76c-756b29fdd777" />

O PPoint é um projeto web desenvolvido em grupo com o objetivo de transformar a experiência do maior São João do mundo em algo mais interativo, inspirado no modelo de retrospectiva do Spotify Wrapped.
A ideia surgiu justamente dessa referência: a forma como o Spotify transforma dados de uso em uma experiência visual e personalizada foi o ponto de partida para pensar o projeto aplicado a eventos.

## Sobre a ideia

Em eventos grandes, é comum acompanhar a programação no momento, mas depois não lembrar exatamente o que foi vivido. O PPoint foi pensado para resolver isso, permitindo que o usuário acompanhe o evento e registre sua própria experiência ao longo dos dias.

A proposta inclui:

* visualização da programação por dia
* acompanhamento de horários
* marcação de presença em shows
* avaliações
* registro de experiências durante o evento

Com isso, a ideia é evoluir para uma retrospectiva personalizada, semelhante ao que o Spotify faz, mas aplicada ao contexto de eventos.

## Como o site funciona na prática

O funcionamento do PPoint foi pensado de forma simples e centrada no usuário. Ao acessar o sistema, o usuário pode navegar pela programação dos dias do evento e interagir com ela.

Durante o uso, ele consegue:

* marcar em quais dias esteve presente
* selecionar os shows que assistiu
* avaliar os shows (por exemplo, com sistema de notas ou estrelas)
* registrar experiências, como o que consumiu ou momentos vividos

Essas interações vão sendo acumuladas ao longo do evento.

A partir desses dados, o sistema pode gerar uma visão geral da experiência do usuário, como:

* os dias em que ele mais participou
* quais shows ele mais gostou
* quais atividades foram mais frequentes
* possibilidade de identificar padrões de comportamento durante o evento

A ideia central é que, ao final, o usuário tenha uma espécie de “retrospectiva do seu São João”, baseada nas próprias interações dentro da plataforma.

## Desenvolvimento em grupo

O projeto foi desenvolvido em equipe, com o objetivo de que cada integrante pudesse praticar e desenvolver diferentes habilidades dentro do desenvolvimento de software.

Houve divisão de responsabilidades, mas todos tiveram contato com as principais áreas:

* front-end (interface e experiência do usuário)
* back-end (estrutura e lógica da aplicação)
* banco de dados (organização e simulação de dados)

Essa dinâmica permitiu que cada pessoa evoluísse tecnicamente e também entendesse melhor como as partes de um sistema se conectam.

## Tecnologias utilizadas

O projeto foi construído com:

* HTML
* CSS
* JavaScript
* Java

A escolha por tecnologias mais diretas foi intencional, com foco no aprendizado prático e no entendimento completo do funcionamento da aplicação.

---

## Design e interface

Uma das principais preocupações foi a interface.

A referência no Spotify influenciou principalmente:

* organização das informações
* hierarquia visual
* forma de apresentar os dados
* fluidez da navegação

A proposta foi criar uma experiência simples, mas agradável e intuitiva.

---

## Desafios

Um dos principais desafios foi o design.

A tentativa de se aproximar de uma experiência como a do Spotify exigiu um nível de cuidado com interface que o grupo ainda estava desenvolvendo. Foi necessário lidar com:

* organização visual dos elementos
* consistência entre telas
* ajustes finos de layout
* adaptação para diferentes tamanhos de tela

---

## Objetivo do projeto

O PPoint foi desenvolvido principalmente como prática.

O projeto permitiu trabalhar:

* habilidades técnicas (front-end, lógica e organização de código)
* noção de design e experiência do usuário
* trabalho em equipe
* divisão de responsabilidades em um projeto real

Cada integrante pôde evoluir na sua área, mas também entender o sistema como um todo.
