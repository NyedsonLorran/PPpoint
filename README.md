# PPoint

O PPoint é um projeto web desenvolvido em grupo com o objetivo de transformar a experiência no maior São Joãoo mundo, organizado e interativo.

A ideia surgiu a partir da retrospectiva do Spotify (Spotify Wrapped). A forma como o Spotify transforma dados de uso em uma experiência visual e personalizada serviu como principal referência para pensar o projeto.

## Sobre a ideia

Em eventos grandes, é comum a gente acompanhar a programação no momento, mas depois não lembrar exatamente o que viveu. O PPoint foi pensado justamente para isso: permitir que o usuário acompanhe o evento e registre sua própria experiência ao longo dos dias.

A proposta inclui:

* visualização da programação por dia
* acompanhamento de horários
* marcação de presença em shows
* avaliações
* registro de experiências durante o evento

Com isso, a ideia é evoluir para uma retrospectiva personalizada, semelhante ao que o Spotify faz, mas aplicada a eventos.

---

## Desenvolvimento em grupo

O projeto foi desenvolvido em equipe, com a proposta de que cada integrante pudesse praticar e desenvolver habilidades diferentes dentro do desenvolvimento de software.

Houve divisão de responsabilidades, mas todos tiveram contato com as principais áreas:

* front-end (interface e experiência do usuário)
* back-end (estrutura e lógica da aplicação)
* banco de dados (organização e simulação de dados)

Essa divisão permitiu que cada pessoa do grupo evoluísse tecnicamente e também entendesse melhor como as partes de um sistema se conectam.


## Tecnologias utilizadas

O projeto foi construído com:

* HTML
* CSS
* JavaScript
* java

A escolha por tecnologias mais simples foi intencional, focando no aprendizado prático e no entendimento completo do funcionamento da aplicação.


## Design e interface

Uma das preocupações centrais foi a interface.

A referência no Spotify influenciou principalmente:

* organização das informações
* hierarquia visual
* forma de apresentar dados ao usuário
* experiência mais fluida e intuitiva

## Desafios

Um dos principais desafios foi trabalhar o design.
A tentativa de se aproximar de uma experiência como a do Spotify exigiu hgbilidades de desiger que o grupo não possuia 

Além disso, fazer tudo isso sem o uso de frameworks tornou o processo mais trabalhoso, mas também mais rico em aprendizado.


## Objetivo do projeto

O PPoint foi desenvolvido principalmente como uma forma de prática.

A ideia foi utilizar o projeto para desenvolver:

* habilidades técnicas (front-end, lógica e organização de código)
* noção de design e experiência do usuário
* trabalho em equipe
* divisão de responsabilidades em um projeto real

Cada integrante pôde evoluir dentro da sua área, mas também ter uma visão geral do sistema
